# Instructional insights

- Generated artifacts must be derived from one authored token source; CSS, TypeScript, and Swift output should be checked together.
- Scope-local theme controllers require scope-local transition selectors; root-only selectors silently fail for nested themes.
- Low disk capacity makes bounded syntax checks safer than dependency or simulator downloads.

## 2026-10-28 — observed, not generalized effectiveness

- Generic navigation demo alone missed donor search journey. Trace actual caller and meaningful result destinations; preserve explicit fixtures versus host service boundaries.
- Reuse is implementation evidence: IconLabel must actually compose Icon/Text, not merely resemble them with raw spans. Collapse can hide mounted label content with inert semantics instead of losing state.
- Concurrent edits invalidate review snapshots. Freeze source and refresh exact paths before accepting source-backed findings; retain retractions of stale findings.
- Prop/event merging needs behavior tests: consumer cancellation before built-ins, protected disabled/hidden state, property-wise styles and cleanup after drag/unmount.
- Package client directives need build preservation scoped to hook-bearing modules; pure metadata/barrels remain server-readable. SSR/type checks still do not establish browser visuals.
- These observations are covered by current extraction/composition/method guidance; required learner and independent reviews found no justified prose growth this episode.
